# 🌍 Geo7 — Тести з географії для 7 класу

Повноцінний fullstack веб-додаток для тестування знань з географії. Учні можуть
реєструватись, обирати теми та проходити тести з миттєвим підсвіченням
правильних/неправильних відповідей. Адміністратор управляє темами, запитаннями
та користувачами через зручну панель.

## ⚡ Технологічний стек

| Шар        | Технологія                          |
|------------|-------------------------------------|
| Веб-сервер | Nginx (reverse proxy)               |
| Backend    | PHP 8.2-FPM (без фреймворків, PDO)  |
| Frontend   | HTML + CSS + Vanilla JavaScript SPA |
| База даних | MySQL 8.0                           |
| Адмін БД   | phpMyAdmin                          |
| Деплой     | Docker Compose                      |

## 🚀 Швидкий старт (Docker)

### Передумови
- [Docker](https://docs.docker.com/get-docker/) ≥ 24
- [Docker Compose](https://docs.docker.com/compose/) ≥ 2

### Кроки

```bash
# 1. Клонуємо репозиторій
git clone https://github.com/plamagnum/geo7.git
cd geo7

# 2. Копіюємо файл налаштувань (необов'язково — є значення за замовчуванням)
cp .env.example .env

# 3. Запускаємо всі сервіси
docker compose up -d --build

# 4. Перевіряємо статус
docker compose ps
```

### Доступ до сервісів

| Сервіс     | URL                        | Опис                         |
|------------|----------------------------|------------------------------|
| Додаток    | http://localhost:8080      | Основний веб-інтерфейс       |
| phpMyAdmin | http://localhost:8081      | Управління базою даних       |
| MySQL      | localhost:3306             | Пряме підключення до БД      |

### Зупинка

```bash
docker compose down          # зупинити без видалення даних
docker compose down -v       # зупинити та видалити дані MySQL
```

## 🌐 API Endpoints

### Авторизація — `GET/POST /api/auth.php`

| Метод | Параметр         | Опис                      |
|-------|------------------|---------------------------|
| POST  | `?action=register` | Реєстрація нового учня  |
| POST  | `?action=login`    | Вхід                    |
| GET   | `?action=check`    | Перевірка сесії         |
| POST  | `?action=logout`   | Вихід                   |

### Теми — `/api/topics.php`

| Метод  | Опис                             | Права      |
|--------|----------------------------------|------------|
| GET    | Список всіх тем з кількістю запитань | Всі    |
| POST   | Створити тему                    | Адмін      |
| PUT    | Оновити тему                     | Адмін      |
| DELETE | Видалити тему                    | Адмін      |

### Запитання — `/api/questions.php`

| Метод  | Параметри          | Опис                     | Права   |
|--------|--------------------|--------------------------|---------|
| GET    | `?topic_id=X`      | Запитання по темі        | Всі     |
| GET    | `?all=1`           | Всі запитання            | Адмін   |
| POST   | —                  | Створити запитання       | Адмін   |
| PUT    | —                  | Оновити запитання        | Адмін   |
| DELETE | —                  | Видалити запитання       | Адмін   |

### Тест — `GET /api/quiz.php`

| Параметр   | Опис                                 |
|------------|--------------------------------------|
| `topic_id` | ID теми (обов'язковий)               |
| `limit`    | Кількість запитань (за замовчуванням: 10) |

### Результати — `/api/results.php`

| Метод | Опис                                          | Права             |
|-------|-----------------------------------------------|-------------------|
| GET   | Отримати результати (свої або всіх для адміна) | Авторизований     |
| POST  | Зберегти результат тесту                      | Авторизований     |

### Імпорт — `POST /api/import.php`

| Параметр       | Опис                            |
|----------------|---------------------------------|
| `?source=url`  | Імпорт з URL (body: `{url}`)   |
| `?source=json` | Імпорт з JSON тексту (body: `{json}`) |

---

## 📥 Формат JSON для імпорту

```json
{
  "topic": "Назва теми",
  "questions": [
    {
      "question": "Текст запитання?",
      "options": ["Варіант A", "Варіант B", "Варіант C", "Варіант D"],
      "correct": 0
    }
  ]
}
```

> Поле `correct` — індекс правильної відповіді (0=A, 1=B, 2=C, 3=D)

## 🗄️ Схема бази даних

```sql
users          — користувачі (id, username, password_hash, role, created_at)
topics         — теми (id, name, description, created_at)
questions      — запитання (id, topic_id, question_text, option_a–d, correct_option, created_at)
quiz_results   — результати (id, user_id, topic_id, score, total_questions, completed_at)
```

## 🎨 Інтерфейс

### Секції додатку

| Секція          | Опис                                                           |
|-----------------|----------------------------------------------------------------|
| **Авторизація** | Вхід / реєстрація з автоматичним логіном після реєстрації     |
| **Теми**        | Картки тем з іконками, описом та кількістю запитань           |
| **Тест**        | Прогрес-бар + запитання + 4 кнопки відповідей (A–D)          |
| **Результат**   | Рахунок, відсоток, мотиваційне повідомлення                   |
| **Результати**  | Таблиця з усіма пройденими тестами                            |
| **Адмін-панель**| CRUD тем, запитань, користувачів + імпорт JSON               |

### Функції UI
- 🌙 **Темна/світла тема** — перемикач у хедері, зберігається в localStorage
- 📱 **Mobile-first** — адаптивний дизайн, гамбургер-меню на мобільних
- ✅ **Підсвічення відповідей** — зелений (правильно) / червоний (неправильно)
- ⏱️ **Автоперехід** — наступне питання через 1.5 с після відповіді
- 📊 **Прогрес-бар** — показує прогрес під час тесту
